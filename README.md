# dxmisc
DxMisc is a collection of DirectX and HLSL code demonstrating different lighting and rendering effects, from simple diffuse and ambient lighting to more complicated techniques like normal mapping, shadow mapping and post processing.

Most of the test scenes contain a single object, which you can rotate by pressing the **Right** and **Left** arrow keys:

![Soft shadow mapping](https://raw.githubusercontent.com/george7378/dxmisc/master/_img/1.png)
![Normal mapping](https://raw.githubusercontent.com/george7378/dxmisc/master/_img/2.png)
![Post processing](https://raw.githubusercontent.com/george7378/dxmisc/master/_img/3.png)

There's also the *DxWater* demo which is built around a custom water shader, and brings together a bunch of the other techniques in a little self-contained room that you can explore.

The **WASD** keys will move the camera (you can hold **Q** to run), **Left mouse** will grab/release the light (when close enough) and the **Up**/**Down** arrow keys will change the water level:

![Calm pool](https://raw.githubusercontent.com/george7378/dxmisc/master/_img/4.png)
![Flooding](https://raw.githubusercontent.com/george7378/dxmisc/master/_img/5.png)
